# "Detecting Near-Duplicates for Web Crawling" implementation with PySpark

## "Big Data" Course Project

This paper reproduces the findings of the “Near-Duplicate Detection for Web 
Crawling” work, using PySpark to scale the proposed algorithm across different datasets, 
feature models and parameter values.
